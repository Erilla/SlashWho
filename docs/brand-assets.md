# Brand assets

The small source links in the web UI use the unmodified brand marks below. They
are image files rather than traced or hand-drawn SVG paths so the source marks
remain recognisable and their artwork is not altered.

| Asset                                          | Source and usage terms                                                                                                                                                                                                                                                                                                                                                   |
| ---------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `apps/web/public/brand/raiderio-mark.png`      | Raider.IO's public asset repository: [`RaiderIO/keystone.guru.assets`](https://github.com/RaiderIO/keystone.guru.assets/blob/main/images/external/raiderio/logo_mark.png). Raider.IO's [logo policy](https://support.raider.io/kb/website-policies-and-rules/use-of-the-raider-dot-io-logo) permits use with proper accreditation and says the logo must not be altered. |
| `apps/web/public/brand/warcraft-logs-mark.png` | Warcraft Logs' official branding page, served from [`assets.rpglogs.com`](https://assets.rpglogs.com/cms/WCL_Icon_57fc009f4e.png). The [RPGLogs branding guidance](https://www.archon.gg/classic-vanilla/articles/help/rpg-logs-branding-information) identifies these as Warcraft Logs marks and says not to recolor or edit them.                                      |

The assets are displayed at a small responsive size without recoloring, tracing,
or additional decoration. The surrounding links retain accessible labels,
safe new-tab handling, focus visibility, and evidence-state classes for kill
and wipe links.
