# Applicant Sheet watcher

The worker can read only `'Form Responses'!F2:F` through the Sheets values API and start discovery plus evidence for new supported character links. It never writes to the Sheet. The first successful read after activation establishes a baseline; existing responses produce no intents. Occurrence counts, not row positions, track later changes. Reorders are inert; an increased count creates a new intent, including after a deletion observed by a prior poll. A delete and re-add entirely between polls cannot be distinguished from no change.

The watcher is disabled by default. Before enabling, arrange **viewer** access to the specific Sheet for a dedicated Google service account. The credential owner must retain the ability to rotate or revoke the key and remove sharing. Configure `APPLICANT_SHEET_ID`, `APPLICANT_GOOGLE_SERVICE_ACCOUNT_EMAIL`, and `APPLICANT_GOOGLE_PRIVATE_KEY` as worker secrets. The key uses `\n` for line breaks. The requested OAuth scope is `spreadsheets.readonly`; the range is a narrow data read, not a permission boundary for the account.

Set `APPLICANT_POLL_CADENCE_MS`, `APPLICANT_ADMISSIONS_PER_TICK`, `APPLICANT_ADMISSIONS_PER_DAY`, `APPLICANT_BACKLOG_LIMIT`, `APPLICANT_QUEUE_DEPTH_LIMIT`, `APPLICANT_MINIMUM_POINTS`, and `MAINTAINER_ALERT_WEBHOOK_URL` explicitly before setting `APPLICANT_WATCHER_ENABLED=true`. Measure recent `character_evidence_run_costs` for own credentials and the Warcraft Logs allowance before choosing limits. The worker also requires remaining points above 120% of the largest measured cost in the last 28 days. The existing evidence worker remains serial and applies its own points gate.

Set `APPLICANT_WATCHER_ENABLED=false` to pause reads and dispatch. The outbox remains durable. Watch count-only `applicant_sheet_poll`, `applicant_sheet_drain`, and `applicant_sheet_tick_failed` events; a repeated failure, a backlog near its configured limit, or a spent allowance requires operator attention. The first activation intentionally drops all previously visible responses as baseline. Do not reset the `applicant_source_*` tables unless a new baseline is intended. Revoking access causes failed polls without changing the durable cursor.

Only normalized character identities, numeric Warcraft Logs IDs, occurrence counts, timestamps, and outbox state are stored. Raw Sheet cells, URLs, adjacent applicant answers, and credentials are never stored or logged by this watcher. No production Sheet access or permission changes are part of issue #444's code delivery.
